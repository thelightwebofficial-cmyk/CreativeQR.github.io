# Contributing to CreativeQR

Thanks for helping improve CreativeQR.

## Before opening a change

- Keep CreativeQR client-side unless a backend is explicitly documented.
- Do not add API keys, passwords, tokens, or other secrets.
- Treat QR/barcode content as untrusted input.
- Keep scanned links from opening automatically.
- Preserve keyboard and mobile accessibility.
- Test QR and barcode generation after changes.
- Test the GitHub Pages deployment workflow when changing deployment files.

## Pull requests

Please describe:

1. What changed
2. Why it changed
3. How you tested it
4. Any browser compatibility considerations

Small, focused pull requests are easier to review and maintain.
