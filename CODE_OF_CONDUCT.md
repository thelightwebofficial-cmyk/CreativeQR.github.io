# Code of Conduct

## Our standard

CreativeQR is intended to be a welcoming technical project. Contributors should communicate respectfully, focus on the work, and avoid harassment, discrimination, personal attacks, or deliberately disruptive behavior.

## Reporting

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than opening a public issue with exploit details.

For ordinary project concerns, open a GitHub issue with enough context for the maintainers to reproduce or understand the problem.
